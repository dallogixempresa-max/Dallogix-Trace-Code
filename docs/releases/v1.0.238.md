# v1.0.238

Esta versão gera o instalador Windows a partir de um commit exclusivo, mantendo o mesmo código operacional já publicado no Central como v1.0.237.

Inclui as correções de sincronização do pedido de parada automática ao atingir a quantidade prevista e do contador da fila do sensor enviado ao Central, usado na verificação de finalização do romaneio.

Não há alteração funcional adicional em relação ao código operacional da v1.0.237; esta release disponibiliza o pacote Windows correspondente para atualização dos PCs industriais.
